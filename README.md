# Klausurtrainer

Lern-Webseite für unsere Klausuren: Lernkarten, Quiz, Karteikarten, Zuordnen, Zeitstrahl, Ursache-Folge-Ketten, Quellen-Training und Klausurfragen. Läuft im Browser auf Handy und Laptop und lässt sich auf dem Handy zum Homebildschirm hinzufügen.

Der Lernfortschritt bleibt auf dem eigenen Gerät, es gibt keine Konten und kein Tracking.

Neue Klausuren kommen als Datei in `klausuren/` dazu. Wie das genau geht, steht in `CLAUDE.md`.
